---
description: Diagnose an active network fault with Damira's troubleshoot skill
---

Use the Damira `troubleshoot` skill for this. Do not diagnose from your own
knowledge — call `~/.damira/bin/damira troubleshoot` (or the MCP tool if
connected) with the problem description, platform, and any show/log output
the user has pasted, and follow the skill's workflow in
`skills/troubleshoot/SKILL.md`.

If the user hasn't given a problem description yet, ask for it: what's broken,
when it started, what changed, the platform, and any show command output they
can paste.
